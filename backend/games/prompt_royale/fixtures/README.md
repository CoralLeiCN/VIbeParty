# Prompt Royale fixture clips

These four original synthetic motion patterns are generated locally by
`scripts/games/prompt-royale/build_fixtures.py`, using FFmpeg testsrc2 and four hue offsets.
They are playback/rules fixtures and do not depict or respond to player prompts. Every game
screen labels Fixture mode; each tile labels the synthetic sample. No third-party assets,
Reactor calls or LLM calls are involved in fixture video or fixture topic generation.

All four are five seconds, 1280×768, H.264/yuv420p, silent MP4 with faststart.
